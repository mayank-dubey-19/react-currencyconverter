
# 💱 React Currency Converter

A modern and responsive **Currency Converter** built with **React.js** that allows users to convert currencies quickly using real-time exchange-rate data.

The project focuses on practicing React fundamentals such as **components, props, state management, hooks, custom hooks, API integration, and dynamic UI updates**.

## ✨ Features

* 🔄 Convert between multiple currencies
* 💰 Enter a custom amount for conversion
* 🌐 Fetch currency exchange rates using an API
* 🔁 Swap "From" and "To" currencies instantly
* ⚡ Automatically update conversion results
* 📱 Responsive and user-friendly interface
* 🧩 Reusable React components
* 🎯 Custom React Hook for currency conversion logic

## ⚙️ How It Works

1. Select the currency you want to convert **from**.
2. Select the currency you want to convert **to**.
3. Enter the amount.
4. The application fetches the latest exchange-rate data.
5. The converted value is displayed automatically.
6. Use the **Swap** option to quickly switch the currencies.
